# RX store bench

Command: `node /home/lucifer/work/solidjs/store-proto-bench/rx-run.mjs`

Rounds: 9. Mem/alloc runs: 3. Wall: 384.4s. Node v24.16.0.

Warmup stops at 30 ops or 300 ms, whichever first. A sample is a batch aimed at >= 20 ms. update is µs per click (100 clicks per timed call). Clear, re-run, and the create1k/create10k clear-after are outside the timer. frameHash is sha1(app.frame() + class props). serialize() drops attributes, and select only writes class, so class is included or select cannot mismatch. The hashed frame is from a fresh mount with the id counter reset, then a fixed op sequence, so sample count cannot make the hashes disagree.

The test renderer’s createElement ignores static props, so the harness wraps it and applies them with setProp before mount. That cost is not inside the timed click.

Order rotates each round (base, core, plain / core, plain, base / plain, base, core). Children pinned with taskset -c 2.
